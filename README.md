# Punto-переключатель (RU ⇄ EN)

Маленький аналог Punto Switcher: исправляет текст, набранный не в той раскладке,
и опечатки. Windows и macOS. Живёт иконкой в трее / в строке меню.

Логика общая для обеих систем ([core.py](core.py), [layouts.py](layouts.py),
[spell.py](spell.py), словари), системная часть разная:
[punto.py](punto.py) — Windows (только ctypes, без зависимостей),
[punto_mac.py](punto_mac.py) — macOS (pyobjc).

Проверить, что всё на месте, на любой системе:

    py tests.py          # Windows
    python3 tests.py     # macOS

## Установка в один клик

**Windows** — двойной клик по `install-windows.bat`. Он проверит Python,
прогонит тесты, добавит программу в автозагрузку и запустит её с включёнными
авто-режимами. Убрать обратно: `uninstall-windows.bat`.

**macOS** — двойной клик по `install-mac.command`. Он найдёт Python 3,
поставит pyobjc, прогонит тесты, проверит доступ к клавиатуре (и откроет нужный
раздел настроек, если доступа нет), пропишет автозапуск через launchd и
запустит программу. Убрать обратно: `uninstall-mac.command`.

Если macOS не даёт запустить файл двойным кликом, один раз выполните в Терминале:

    cd путь/к/punto-switcher && chmod +x install-mac.command uninstall-mac.command

## Запуск вручную на Windows

    py punto.py          # с консолью (видно сообщения)
    punto.bat            # без окна консоли
    punto.bat --auto     # сразу с авто-раскладкой
    punto.bat --auto --spell   # ещё и с авто-орфографией

Автозагрузка: положить ярлык на `punto.bat` в
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`.

## Запуск вручную на macOS

    python3 -m pip install -r requirements-mac.txt
    python3 punto_mac.py --check      # диагностика: права, раскладки, словари
    python3 punto_mac.py --auto --spell

Нужно разрешение: **Системные настройки → Конфиденциальность и безопасность →
Универсальный доступ** — добавить туда Терминал (или тот python3, которым
запускаете). Без него перехват клавиш не работает, `--check` это покажет.

Автозапуск: отредактируйте путь в `com.punto.switcher.plist`, положите файл в
`~/Library/LaunchAgents/` и выполните
`launchctl load ~/Library/LaunchAgents/com.punto.switcher.plist`.

### Горячие клавиши на macOS

| Клавиши | Действие |
|---|---|
| двойной `Shift` | перевести последнее слово в другую раскладку |
| `⌃⌥L` | то же самое |
| `⌃⌥⇧L` | перевести выделенный текст |
| `⌃⌥S` | исправить опечатку в последнем слове |
| `⌃⌥A` | вкл/выкл авто-раскладку |
| `⌃⌥P` | вкл/выкл авто-орфографию |
| `⌃⌥Q` | выход |

Клавиши `Pause/Break` на маковской клавиатуре нет, поэтому набор другой.
Двойной Shift — как в оригинальном Punto Switcher для Mac; он не срабатывает,
если между нажатиями были другие клавиши.

## Горячие клавиши на Windows

| Клавиши | Действие |
|---|---|
| `Pause` | перевести последнее набранное слово в другую раскладку |
| `Shift+Pause` | перевести выделенный текст (через буфер обмена) |
| `Ctrl+Alt+Pause` | исправить опечатку в последнем слове |
| `Ctrl+Pause` | включить/выключить авто-раскладку |
| `Ctrl+Shift+Pause` | выход |

Правый клик по иконке в трее — меню, двойной клик — переключение авто-режима.
После конвертации раскладка окна переключается на нужную, чтобы можно было
продолжать печатать.

## Автоматический режим

Выключен по умолчанию (включается `Ctrl+Pause` или ключом `--auto` при запуске).
Когда включён, после каждого пробела последнее слово проверяется так:

1. слово есть в `dict_user.txt` — не трогаем никогда;
2. слово есть в словаре своего языка — не трогаем;
3. конвертация даёт слово из словаря другого языка — исправляем;
4. иначе решает триграммная модель: исправляем, только если другая раскладка
   правдоподобнее не меньше чем на `THRESHOLD` нат на символ, и результат
   вообще возможен в том языке (есть гласные, допустимая первая буква).

Словари и модель собраны из частотных списков (по ~48 тыс. слов на язык):
`build_model.py` делает из `ru_50k.txt`/`en_50k.txt` файлы `dict_ru.txt`,
`dict_en.txt` и `model.json`. Свои термины, имена и аббревиатуры, которые
исправлять не нужно, дописывайте в `dict_user.txt` (по слову в строке) —
там уже лежат mqtt, gpio, uart и прочее.

На проверочном наборе: 20 из 20 слов с неверной раскладкой исправлены,
37 из 37 нормальных слов не тронуты.

## Орфография

Работает на тех же словарях: слово, которого нет в словаре, сравнивается со
всеми словами на расстоянии одной правки (вставка, удаление, замена,
перестановка) и заменяется самым частотным из них.

- `Ctrl+Alt+Pause` — исправить последнее слово вручную, оба языка, без
  ограничений осторожности. Восстанавливает ~84% опечаток.
- Авто-орфография (пункт меню в трее или ключ `--spell`) — **только русский**
  и только для правок, характерных для опечаток: перепутанная гласная
  (`нармальному`), пропущенная или лишняя гласная (`сделть`), перестановка
  соседних букв (`привте`), удвоение, мягкий знак. Замены согласных не
  трогаются — именно на них ломается жаргон (`батч`→матч, `флоу`→флот).
  Правило задаётся `AUTO_KINDS` в [spell.py](spell.py).

Измерено: чинит **76%** опечаток такого рода; на 3828 русских словах из ваших
рабочих текстов **ни одного ложного исправления**.

Английский в авто-режиме сознательно отключён: техническая лексика в обычных
словарях отсутствует, и автозамена ломала бы `backend` → `backed`,
`cors` → `cops`, `chown` → `crown`. Для английского — ручная клавиша.

Не проверяются: слова короче 4 (в авто-режиме — короче 5) и длиннее 16 букв,
АББРЕВИАТУРЫ, camelCase, слова с цифрами, всё из `dict_user.txt` и однокоренное
ему (`баг` закрывает `багов`, `деплой` — `деплою`).

Таблица автозамен `replace.txt` — для ошибок, которые не сводятся к одной букве
(`тоесть` → `то есть`, `вобщем` → `в общем`). Формат: `ошибка = замена`,
работает в обоих языках, пополняется вручную.

### Личный словарь

    py learn.py                  # просканировать папку проекта
    py learn.py D:\work C:\notes  # или свои папки
    py learn.py --all            # вместе с английскими словами

Скрипт берёт слова, которых нет в общих словарях, но которые встречаются в ваших
файлах не меньше трёх раз в двух разных файлах, и дописывает их в
`dict_user.txt`. По вашим проектам он собрал ~190 слов: бэкенд, вендинг,
колбэк, провижининг, симкомат, водомат, хендшейк. Запускайте повторно, когда
появится новая тема — так авто-орфография перестанет трогать её лексику.
Латиница по умолчанию не учится: в коде её слишком много мусора.

## Словари

| Файл | Что это | Откуда |
|---|---|---|
| `dict_ru.txt`, `dict_en.txt` | ~48 тыс. частотных слов, порядок = частота | `ru_50k.txt`/`en_50k.txt`, FrequencyWords |
| `words_ru.txt`, `words_en.txt` | 1,5 млн и 370 тыс. словоформ, отсортированы | danakt/russian-words, dwyl/english-words |
| `model.json` | триграммная модель обоих языков | считается из частотных списков |
| `dict_user.txt` | личный стоп-лист | пополняется вручную |

Большие словари не грузятся в память: [wordset.py](wordset.py) ищет в них
бинарным поиском по `mmap` (~14 мкс на слово). Пересобрать всё:
`py build_model.py` плюс сортировка словоформ.

## Файлы

- [core.py](core.py) — общая логика: буфер набранного, замена слова, команды
- [punto.py](punto.py) — Windows: хук клавиатуры, горячие клавиши, трей
- [punto_mac.py](punto_mac.py) — macOS: CGEventTap, строка меню, Text Input Sources
- [tests.py](tests.py) — тесты общей логики, без GUI
- [layouts.py](layouts.py) — таблицы ЙЦУКЕН⇄QWERTY и определение «не та раскладка»
- [build_model.py](build_model.py) — сборка словарей и `model.json` из частотных списков
- `dict_user.txt` — личный стоп-лист слов
- [punto.bat](punto.bat) — запуск без консоли

## Ограничения

- Только русская + английская (US) раскладки.
- macOS-версия написана по документации и **не проверена на живой системе** —
  автор работал на Windows. Общая логика покрыта `tests.py`, системную часть
  (перехват, вставка текста, переключение раскладки) нужно проверить на месте;
  начните с `--check`.
- В окнах, запущенных от администратора, ввод не перехватывается (защита UIPI) —
  чтобы работало и там, запускать программу тоже от администратора.
- Переменная окружения `PUNTO_TEST=1` заставляет учитывать синтетический ввод
  (нужна только автотестам, в обычной работе не выставлять).
